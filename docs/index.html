The datalake for
Brazilian public data.

35 pipelines pull, normalize, and aggregate government data — IBGE, BACEN, TSE, RAIS, Receita Federal, and more — into an open Iceberg lakehouse keyed by município. This page documents the Python package: how to install it, run it against your own AWS account, and what's coming next for querying it as an MCP server.

Install

PyPI · lakebrasil

Core install covers the 35 HTTP/SIDRA pipelines. A handful of sources need optional extras for their file formats — install only what you'll actually run.

lakebrasil

Core — HTTP + SIDRA pipelines, no extras needed.

lakebrasil[excel]

sinisa, mec_ed_superior — .xlsx sources.

lakebrasil[archive]

rais_estab — .7z archive extraction.

lakebrasil[geo]

inpe — shapefiles, geopandas, spatial joins.

lakebrasil[all]

Every extra — all 35 pipelines runnable.

CLI quickstart

lakebrasil <command>

Every pipeline runs through one entry point. A run is fetch → transform → write to Iceberg, but each step is independently skippable.

lakebrasil listList all 35 available pipelines.
lakebrasil run anp_precos --dry-runStage a pipeline to local DuckDB — no Iceberg write, no AWS needed.
lakebrasil run snis --no-fetchSkip re-download, transform + write what's already staged in S3.
lakebrasil dqRun the declarative data-quality checks that gate every Iceberg push.
lakebrasil fetch bacen_ipca_mensalFetch one source's raw files without running the transform step.

Self-host

ICEBERG_WAREHOUSE=…

The Iceberg backend is auto-detected from one environment variable. Your data, your account — nothing here requires talking to a lakebrasil-run service.

A · managed

AWS S3 Tables

Default. Managed Iceberg, queryable from Athena, Spark, DuckDB, or Trino.

export ICEBERG_WAREHOUSE=arn:aws:s3tables:...
export AWS_PROFILE=your-profile
B · zero AWS

MinIO + Nessie

100% OSS, runs via Docker Compose. No cloud account required.

docker compose up -d
export ICEBERG_WAREHOUSE=warehouse
C · portable

Any Iceberg REST

Lakekeeper, Tabular, or any vanilla REST catalog implementation.

export ICEBERG_WAREHOUSE=s3://bucket/warehouse/
export ICEBERG_REST_ENDPOINT=https://...
D · local dev

SQLite + filesystem

Zero-infra — a single path on disk, good for trying a pipeline out.

export ICEBERG_WAREHOUSE=local:///tmp/warehouse

Querying via MCP

Model Context Protocol
● live — 99 tools, 33 sources

lakebrasil-mcp — the live counterpart

A separate, open-source MCP server: github.com/lakebrasil/mcp. It doesn't touch the lake at all — every tool call goes straight to the original source's API in real time (BACEN, IBGE, Câmara, Senado, Portal da Transparência, CNPJ/CEP lookups, and 26 more). No account, no API key, for almost every tool.

lakebrasil — historical lake, 35 batch pipelines, this repo lakebrasil-mcp — live queries, 99 tools, separate repo 
// claude_desktop_config.json
{
  "mcpServers": {
    "lakebrasil": {
      "command": "uvx",
      "args": ["lakebrasil-mcp"]
    }
  }
}

One exception: transparencia_* tools need a free PORTAL_TRANSPARENCIA_API_KEY — see the repo README.
